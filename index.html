What is SimpleSoup?

SimpleSoup is a powerful Python library for downloading videos, playlists, and galleries from multiple platforms. With a simple and intuitive API, you can extract video metadata, download content at various quality levels, and process galleries—all in just a few lines of code.

Built for speed, reliability, and ease of use. Perfect for automation, archiving, and content processing workflows.

🎬

Single Video Download

Download videos at multiple quality levels (360p to 1080p) with just one simple request.

📺

Playlist Support

Download entire playlists with custom skip and count parameters. Perfect for batch processing.

🖼️

Gallery Downloading

Extract and download image galleries from various platforms using gallery-dl integration.

📊

Metadata Extraction

Get title, creator, views, likes, comments, duration, and more without downloading video.

🔐

Cookie Support

Automatic cookie fallback system for accessing restricted or protected content.

📈

Progress Tracking

Real-time progress callbacks showing download percentage, speed, and mode.

Installation

Install SimpleSoup from PyPI:

pip install simplesoup

For Gallery Support:

pip install "simplesoup[gallery]"

After installation, you can start using SimpleSoup in your Python projects.

⚡ Quick Start Example

from simplesoup import rz

url = "https://example.com/video"

result = rz({
    "video[4]": "video",
    "title": "title",
    "creator": "creator",
    "views": "views"
}, url)

print("Title:", result["title"])
print("Creator:", result["creator"])
print("Views:", result["views"])

Key Capabilities

🎯 Video Quality Options

video[0] = Audio | video[2] = 360p | video[3] = 480p | video[4] = 720p | video[5] = 1080p

📋 Metadata Fields

title, creator, url, views, likes, count (comments), time (duration), thumbnail

🎞️ Playlist Syntax

playlist: "QUALITY:SKIP:COUNT" - Download specific videos from playlists

🖼️ Gallery Mode

Download entire image galleries from supported platforms

🔄 Multiple Values

Request video + metadata in a single call for efficiency

💾 Auto Save

Default: /storage/emulated/0/Download/ReiDownloader/
